# ble-esp-demo

> ⚠️ **План на 01.12.2026:** репозиторий будет удалён, код переедет в новый репозиторий про **air-quality** (перед удалением — создать replacement и перенести эту историю, либо просто переименовать репо на GitHub: rename сохраняет историю и ставит редирект со старого адреса). Локальная папка `active\ble\elephant-embed-ble\esp32` остаётся на месте до перемещения.

Отладочный BLE-стенд на ESP32: датчики → красивый WebUI → BLE-реклама и GATT.

> **Важно про расположение.** Папка лежит в `active\ble\elephant-embed-ble\esp32`, но этот проект — **не часть elephant-ble и не прошивка elephant-embed-ble**. Это самостоятельное устройство, ответвление от наработки **air-quality** (`active\air-quality`). В `elephant-embed-ble\` оно оказалось исторически при переезде со старого ПК. Папки `esp32\`, `stm32\`, `wch\` внутри `elephant-embed-ble\` — зарезервированные места под тестовые прошивки для платформ, чтобы в случае отсутствия Bluetooth на компьютере можно было использовать разработанные платы. Пока реальная прошивка есть только в `esp32\` (этот репозиторий), ничего перемещать не требуется.

## Роль проекта

**Главный тестовый девайс для отладки [`elephant-ble`](https://github.com/andrewoficial/elephant-ble)** — скан с разбором рекламы, подключение, дерево GATT, NUS-обмен проверяются живым устройством.

## Что на плате и что умеет

| Блок | Детали |
|---|---|
| Датчик давления/температуры | **BMP180** по I2C (`src/bmp180.c`), с компенсацией и проверкой диапазона |
| PID-сенсор (газ, аналоговый) | читается в милливольтах (`app_get_pid_millivolts`, диапазон 0–3500 мВ) |
| BLE-реклама | manufacturer data: company ID `0xFFFF` + IPv4-адрес устройства + PID в милливольтах (`src/ble_nus.c`) — по рекламе видно адрес WebUI и уровень сигнала датчика |
| GATT | NUS-совместимый сервис: команды и поток данных (`src/protocol.c`, `src/ble_nus.c`) |
| WebUI | **«Orbit — ESP32»**: панель устройства — мониторинг и управление (`src/web_page.h`, `src/web_server.c`) |
| Хранение | `src/storage.c`, таблица разделов `partitions.csv` |

## Сборка

Проект собирается как ESP-IDF (`src/CMakeLists.txt`, `sdkconfig.esp32dev`) и открывается в PlatformIO (`platformio.ini`).

- `managed_components\` в `.gitignore`: восстанавливается ESP-IDF из `idf_component.yml` + `dependencies.lock` (оба в git).
- Артефакты `.pio\` и `release\` игнорируются; релизные заметки — `FIRMWARE_RELEASE.md`.
- Внутри репо есть локальные `refs/agents/...` и `refs/cline/...` — чекпоинты прежних агентов, это не ветки.

## Смежное

- [`elephant-ble`](https://github.com/andrewoficial/elephant-ble) — BLE-библиотека (C-ядро + JNA), для которой этот стенд — живой тестовый девайс.
- `active\air-quality` — наработка по качеству воздуха, от которой проект ответвился.
